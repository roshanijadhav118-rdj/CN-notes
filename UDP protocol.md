UDP — User Datagram Protocol

UDP is a connectionless transport protocol designed with minimal protocol mechanisms. 
It does not provide guaranteed delivery or ordered delivery. RFC Editor
Because UDP has less protocol overhead than TCP, 
it is useful when low latency and application-controlled delivery are more important than guaranteed delivery.

Key Features
Connectionless communication
Low protocol overhead
No guaranteed delivery
No guaranteed ordering
No retransmission mechanism
Uses port numbers
Suitable for latency-sensitive applications
