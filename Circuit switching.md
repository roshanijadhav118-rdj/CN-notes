Circuit Switching
In circuit switching, a dedicated communication path is established between the sender 
and receiver before data transmission begins.


Working
Connection establishment – A dedicated path is created.
Data transfer – All data follows the same path.
Connection termination – The path is released after communication


Example: Traditional telephone networks.

Advantages
Fixed and dedicated path.
Data arrives in the correct order.
Predictable transmission performance.
No need to find a new route for every piece of data.

Disadvantages
Wastes bandwidth when no data is being transmitted.
Connection establishment takes time.
Not efficient for bursty computer data.
A failure in the dedicated path can interrupt communication.
