The TCP/IP

(Transmission Control Protocol/Internet Protocol) model is the practical networking model 
used for communication over the Internet. It defines how data is transmitted between devices.

It has 4 layers:

Application Layer – Provides network services directly to applications.
Examples: HTTP, FTP, DNS, SMTP
Transport Layer – Provides end-to-end communication, reliability, and flow control.
Protocols: TCP, UDP
Internet Layer – Handles logical addressing and routing of packets between networks.
Protocol: IP
Network Access Layer – Handles transmission of data over the physical network and communication with hardware.

Examples: Ethernet, Wi-Fi
