Types of address in TCP/IP model

1) Physical address
   - Datalink layer
   - Ex: 00:1A:2B:4D:3C:9A

2) Logical Address
   - Also called IP address
   - Network layer
   - Ex: 192.168.1.10

3) Port address
   - Transport layer
   - Ex: 16 bit long, 0 to 65535

4) Specific address
   - Application address
   - Eg: www.leetcode.com
