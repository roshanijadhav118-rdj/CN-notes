TCP — Transmission Control Protocol

TCP is a connection-oriented and reliable transport protocol.
Before exchanging application data, TCP establishes a connection between the
communicating endpoints. It then uses sequence numbers, acknowledgements, checksums,
and retransmission mechanisms to provide reliable and ordered data delivery. �
