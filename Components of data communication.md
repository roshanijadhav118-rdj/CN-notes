Components of Data Communication System

- DCM is a system that enables exchange of data among devices.

1) Sender
   - It converts data into signals & sends it to other devices.
   - Ex: Computer, Laptop

2) Message
   - Actual information will be transmitting.
   - Ex: Text, Image, Audio

3) Transmission Medium
   - It is path through which data travels.
   - Ex: Coaxial cable, Bluetooth

4) Receiver
   - It converts signals back in user understandable language.
   - Ex: Smartphone, Printer, Server
  
5) Protocol
   - Set of rules that governs data communication
   - Ex: HTTP, FTP,TCP/IP
