OSI Model

The OSI (Open Systems Interconnection) model is a 7-layer conceptual model 
developed to ISO how different networking systems communicate.
It is mainly used for understanding, designing, and troubleshooting networks.

The 7 layers are:

Physical Layer – Transmits raw bits through cables, radio signals, or other physical media.
Data Link Layer – Provides node-to-node communication, framing, MAC addressing, and error detection.
Network Layer – Handles logical addressing and routing of packets.
Example: IP
Transport Layer – Provides end-to-end delivery, reliability, flow control, and error recovery.
Examples: TCP, UDP
Session Layer – Establishes, manages, and terminates communication sessions.
Presentation Layer – Handles data translation, encryption/decryption, and compression.
Application Layer – Provides network services to end-user applications.

Examples: HTTP, FTP, DNS, SMTP
