📡 Modes of Data Transfer in Computer Networks
Modes of data transfer describe how data moves between two communicating devices. 
They are mainly classified based on the direction of communication.

1. Simplex Mode
Data flows in only one direction.
One device acts as the sender, and the other as the receiver.
The receiver cannot send data back.
Example: Keyboard → Computer, TV broadcasting.
Key point: Sender → Receiver

3. Half-Duplex Mode
Data can flow in both directions, but not simultaneously.
Devices take turns transmitting data.
Common in communication systems where simultaneous transmission is unnecessary.
Example: Walkie-talkie.
Key point: A → B or A ← B

5. Full-Duplex Mode
Data flows in both directions simultaneously.
Both devices can send and receive at the same time.
Provides better communication efficiency.
Example: Telephone/mobile call.
Key point: A ↔ B simultaneously

Modes of data transfer define the direction and manner
in which data is exchanged between communicating devices.
The three basic modes are Simplex, Half-Duplex, and Full-Duplex.
